## Provenance of these files

The Markdown in this directory is not Wizards' original PDF. It is the
**"SRD reForged"** Markdown adaptation by *oldmanumby*, retrieved from
https://github.com/oldmanumby/dnd.srd.5.1 (commit recorded in
`PROVENANCE.txt`). That project describes itself as a "reMastered,
reOrganized, and rePublished" Markdown conversion of the SRD 5.1 PDF:
the rules text is preserved, but it is split across files and reorganized
relative to the original document.

CC-BY-4.0 permits adaptations, so redistributing it here is fine. Two
consequences worth stating plainly:

1. Section ordering and file layout are the adapter's, not Wizards'.
   Citation anchors produced by Table Oracle therefore point into *this*
   adaptation, which is what ships in this repo and what a reader can
   actually open and check.
2. Table Oracle makes no claim that this transcription is error-free. Any
   transcription discrepancy in the source will be faithfully reproduced
   in an answer's citation.
